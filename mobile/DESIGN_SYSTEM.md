# Design System

## Color Palette

- Primary: #B88AE5
- Secondary: #FF6B81
- Accent: #D9BFD7
- Background: #0F0F12
- Surface: #171B22
- Surface alt: #1F232A
- Text: #F3F0F5
- Muted: #C4C4CE
- Border: #2A2D35
- Success: #2F8F66
- Warning: #D8A133
- Danger: #D9534F

## Typography Scale

- xs: 11/16, medium
- sm: 13/18, medium
- md: 15/22, medium
- lg: 18/26, semibold
- xl: 24/32, bold
- xxl: 30/38, bold

## Spacing

- xs: 4
- sm: 8
- md: 12
- lg: 16
- xl: 20
- xxl: 24

## Components

- Button: primary, secondary, outline variants
- Input: label + validation state
- Card: neutral content surface with elevated border and shadow
- Badge: status and labels
- Avatar: user icon initials
- Modal: controlled dialog overlay

## Accessibility

- Ensure min tap targets of 44x44 px
- Preserve contrast ratios on dark surfaces
- Use semantic labels for interactive controls
- Keep the theme calm, readable, and low-glare for evening use
