# User Guide

## Getting Started

### 1. Create Account

1. Go to the app
2. Click "Sign Up"
3. Enter your email and password
4. Verify your email

### 2. Invite Your Partner

1. Go to Settings
2. Click "Invite Partner"
3. Share the link with your partner
4. They sign up using the link

## Features

### Memories

#### Add a Memory

1. Go to Memories page
2. Click "Add Memory"
3. Upload photos
4. Add title and description
5. Click "Save"

#### View Memories

- Scroll through timeline
- Click on memory to view details
- Use filters to find specific memories

### Goals

#### Add a Goal

1. Go to Goals page
2. Click "Add Goal"
3. Enter goal name and target
4. Set current progress
5. Click "Save"

#### Update Progress

1. Click on goal
2. Adjust progress slider
3. Click "Update"

### Messages

#### Send a Message

1. Go to Messages page
2. Type your message
3. Click "Send" or press Enter

#### View Message History

- Scroll through conversation
- Use search to find old messages

### Todos

#### Add a Todo

1. Go to Todos page
2. Click "Add Todo"
3. Enter task name
4. Click "Save"

#### Mark Complete

- Click checkbox next to todo

### Daily Love Notes

#### Set Reminder Time

1. Go to Settings
2. Find "Daily Love Notes"
3. Set preferred time
4. Click "Save"

### Calendar

#### Add Event

1. Go to Calendar page
2. Click on date
3. Click "Add Event"
4. Enter title and type
5. Click "Save"

### Memory Lane

View memories from this day in previous years:

1. Go to Memory Lane page
2. Browse memories
3. Click to view details

### Mood Tracker

#### Log Your Mood

1. Go to Mood Tracker
2. Select your mood emoji
3. Add optional note
4. Click "Log Mood"

### Financial Goals

#### Add Goal

1. Go to Finance page
2. Enter goal name
3. Set target amount
4. Enter current amount
5. Click "Add Goal"

#### Update Progress

1. Find your goal
2. Enter amount to add
3. Progress updates automatically

### Workout Together

#### Start Workout

1. Go to Wellness page
2. Click "Workout Together" tab
3. Select workout
4. Click "Complete Workout"

### AI Features

## Troubleshooting

### App Not Loading

1. Refresh the page
2. Clear browser cache
3. Check internet connection
4. Try incognito mode

### Notifications Not Working

1. Check browser notification permissions
2. Ensure you're logged in
3. Check Settings > Notifications
4. Try re-subscribing

### Can't Upload Photos

1. Check file size (max 5MB)
2. Use supported formats (JPG, PNG)
3. Check internet connection
4. Try different browser

## FAQ

**Q: Is my data private?**
A: Yes! All data is encrypted and only accessible to you and your partner.

**Q: Can I export my data?**
A: Yes! Go to Settings > Export Data.

**Q: Can I delete my account?**
A: Yes! Go to Settings > Delete Account.
