# Device compatibility matrix

| Device          | OS                      | Focus                                |
| --------------- | ----------------------- | ------------------------------------ |
| iPhone 12/13    | iOS 17                  | Core auth, chat, calls               |
| Pixel 5/7       | Android 13/14           | Maps, notifications, permission flow |
| low-end Android | Android 12              | Performance, offline sync            |
| tablet          | iPadOS / Android tablet | Layout stability                     |

## Additional checks

- dark mode rendering
- permission prompts
- network offline recovery
- battery and thermal behavior during calls and location sharing
