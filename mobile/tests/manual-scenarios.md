# Manual test scenarios

## Auth scenarios

1. Login with valid user credentials.
2. Check invalid password error handling.
3. Confirm redirect after logout.

## Messaging scenarios

1. Send message online.
2. Disable network and send message.
3. Re-enable network and verify sync.
4. Verify pending count resets after sync.

## Location scenarios

1. Grant location permission.
2. Toggle location share on.
3. Confirm map shows current location.
4. Toggle off and verify privacy indicator.

## Call scenarios

1. Initiate audio call.
2. Initiate video call.
3. Test incoming call modal.
4. End call and confirm timer resets.

## AI scenarios

1. Generate gift ideas.
2. Generate date ideas.
3. Generate message suggestions.
4. Validate graceful failure when offline or API unavailable.
