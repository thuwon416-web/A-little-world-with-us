# Couple unlink behavior

Unlinking revokes the accepted couple link. It does not automatically delete relationship data.

## What is preserved

- **Photos and memories:** Existing records and stored media are preserved. They are no longer treated as active shared content after unlinking.
- **Chat:** Existing messages and attached media are preserved. No messages are automatically deleted.
- **Location history:** Existing history is preserved, but live location sharing stops when the couple link is revoked.
- **AI context:** Existing AI-related context is preserved according to each user's privacy settings and remains private to the user who owns it.

The application does not automatically delete photos, memories, chat, location history, or AI context during unlinking.

## Manual export and deletion

Before unlinking, users should use the available export features if they need an archive of their data. After unlinking, users can remove individual records through the relevant feature's delete controls where available. Storage objects should be removed together with their related record when a feature provides that option.

Deletion is intentionally manual and irreversible. Contact the application administrator if a record cannot be removed through the UI.
