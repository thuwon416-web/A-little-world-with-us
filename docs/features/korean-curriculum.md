# Korean Curriculum

The Korean curriculum is original product content. Yonsei is an external proficiency/difficulty benchmark, not a source for copied lessons, dialogues, exercises, images, audio, or answer keys.

Current learner-facing direction: Levels 1–6. Levels 4–6 implementation foundations exist; content completeness and QA remain release-gated.

Future layers include Our Korean, Structured Korean, Korea Life, Couple Korean, adaptive review, speaking practice, richer audio, and AI tutoring. This domain roadmap is subordinate to root ROADMAP.md.
