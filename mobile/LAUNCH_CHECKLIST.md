# Launch Checklist

## Pre-launch

- Confirm app metadata and app identifiers
- Validate dark theme and accessibility colors
- Test login, chat, calls, and notifications flows
- Verify offline-first sync works after reconnect
- Check privacy opt-in for location and notification features

## Launch day

- Confirm Supabase environment values are set
- Check app store listing metadata
- Validate release builds from Expo
- Monitor crash logs and performance for first build

## Post-launch

- Review retention and engagement data
- Monitor push notification delivery
- Track bug reports and release notes feedback
- Prepare follow-up improvements for version 1.1

## Marketing

- Prepare landing page and launch announcement
- Gather screenshots and feature highlights
- Validate app store assets and description

## Support

- Document troubleshooting for login, notifications, and permission issues
- Prepare a quick-start guide for users
- Confirm support email and privacy URL are active
